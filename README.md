# TTDL 2

Download TikTok profile videos and photos in HD without watermarks.

## Install

[Windows installer](https://github.com/mr-szgz/ttdl2/releases/download/v3.0.0/TTDL2-3.0.0-windows-x64-Setup.exe) · [GitHub releases](https://github.com/mr-szgz/ttdl2/releases)

### To run from source:

```powershell
uv run ttdl2
```
